# Generated Electron + gluestack-ui app

This app was generated by AppGenerator. It is an independent project: it
does not track changes made to the generator's template after generation,
and there is no update or eject path.

## Running

```
npm start
```

This builds the renderer with Vite and launches Electron. If the app was
generated with `--no-install`, run `npm ci` first - and the first launch
will then need to download the Electron binary (one-time, requires
network).

## Self-check

```
npm run smoke
```

Builds the app and launches it in an automated headless-friendly mode that
asserts the placeholder screen rendered and exits non-zero on failure. This
is the same mechanism the generator's own test suite uses to prove the
generated app actually works - useful if something looks wrong after
editing the template-derived files.

## Where the UI comes from

The placeholder screen renders a component from the UI library through
`src/ui/index.jsx` - the single place this app imports from the UI
library. Everything else imports from `src/ui`, not from the library
directly. That seam is what makes it possible to swap the UI library later
without touching the rest of the app.

## Extending

There is no preload script in this template because there is no IPC yet.
If you need the renderer to talk to the main process, add a
`electron/preload.cjs`, load it via `webPreferences.preload` in
`electron/main.cjs`, and expose only what you need through
`contextBridge`.
